Gaze recorder

Records … for the gaze accuracy benchmark: 16 calibration dots, then a dot that moves over each Cell of the Passage. Look at the dot the whole time and keep the window as it is.

This stores face landmarks (no video, no images) in a file on this computer. Only continue if the Learner gave written consent. The file stays out of git and is deleted when the consent period ends.

  1. Enable the camera, then start. The page goes fullscreen.
  2. Follow the dots. Do not resize the window, press Esc or switch tabs: that discards the recording.
  3. When it says saved, close the page.
